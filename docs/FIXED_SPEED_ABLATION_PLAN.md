# 固定速度对照：训练前参数声明与完成结果

**2026-11-06更新**：8m PPO、正常/清零/重复评估和配对检查均已完成。三密度到达率100%/98%/81%，实际平均速度2.023/2.010/1.950m/s；结果与限制见[复现报告](REPRODUCTION_REPORT.md)。以下保留训练前声明，未根据结果更换目标速度或系数。

证据为可获取的[2024预印本V-B节](https://arxiv.org/html/2402.08381v1#S5.SS2)和固定SHA的官方源码。未将2024预印本当作已取得的2025最终版。

## 已核实的差异

预印本的MAVRL-Fixed保留记忆表征，通过将速度奖励项改为`lambda_v * abs(v_horizontal - v_desired)`，鼓励策略维持目标速度。论文描述速度惩罚权重较大，但低于碰撞惩罚；并通过奖励参数调整构建成功率/速度Pareto曲线。该定义不是直接将速度向量归一化，也不是给加速度动作外加固定速度控制器。

本项目当前主实现保留官方公开源码的分段速度惩罚：仅在水平速度超过3m/s时使用速度项，final系数为-0.05。源码仓库及AvoidBench中未检索到明确的MAVRL-Fixed训练分支或完整固定速度参数配置。论文中用于分组比较的1.5/2.0/2.5m/s不能据此直接当作已经核实的`v_desired`训练参数。

## 后续实施边界

1. 单独实验配置启用目标速度误差项，保持基线的网络、加速度/yaw接口、其他奖励及运动学。基线配置继续使用原速度项。
2. 必须在运行前声明`v_desired`、速度惩罚系数、作用阶段及候选参数预算。未找到原始具体值时，记录为本项目选择，不能标成官方精确配置。
3. 复用同一past+current表征，重新初始化并按相同8m PPO预算训练；不通过评估时裁剪动作制造固定速度结果。
4. 报告实际速度分布、成功率、碰撞率、平均目标推进速度/飞行速度等，并保留启动、减速和失败轨迹。受加速度约束，目标速度奖励不能保证每一步精确恒速。
5. 在与可变速度策略实际平均速度相近的条件下比较，并明确匹配规则；不能将飞得更慢导致的碰撞减少直接解释成更优算法。

## 2026-11-05训练前参数声明

现已实现独立配置`configs/isaac_capture2_fixed_speed.json`：`speed_mode=target`、`target_speed=2.0 m/s`、速度项系数沿用final的`-0.05`，即`-0.05*abs(v_horizontal-2.0)`。选择2.0m/s是为了落在已观察到的主基线三密度平均速度1.91–2.23m/s范围内；保持原速度项系数可减少同时改变的参数。具体数值为本项目选择，不声称为原论文公开的精确配置。

仅final奖励阶段启用目标速度项，initial预热阶段保留原奖励；其他项、终止覆盖、动作和动力学不变。保持相同past+current表征、seed=0、64环境、8m PPO预算和相同新取帧设置。候选预算只包含这一组参数，不在看到结果后挑选最有利组合。两项单元测试覆盖只改变final速度项、运动学不变和终止奖励优先；此段为训练前声明；完成结果见上方更新。

`recover_capture.py`在取帧资格检查通过后依次执行主基线PPO、current-only PPO、目标速度PPO，再生成两个配对比较。实际速度未匹配时不宣称等速度性能优劣；单组目标速度不能替代论文的完整Pareto曲线。
