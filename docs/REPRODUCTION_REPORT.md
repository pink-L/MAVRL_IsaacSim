# MAVRL 在 Isaac Sim 静态圆柱环境中的复现报告

**本轮交付版，2026-11-06。**环境迁移、四阶段训练、三组等预算PPO、三密度评估和重复性/产物检查已完成；队列于北京时间08:29:27结束。本报告将工程完成与研究结论分开：导航能力和历史状态依赖有实际证据，但本轮未观察到“重建过去帧”相对current-only提高到达率；变速与目标速度对照的差异仅限定于本次单种子、单组目标速度设置。

完整运行与复跑命令见[HANDOFF.md](HANDOFF.md)。机器可读结果、权重SHA256及图表见[交付目录](../artifacts/delivery_20261106/)。多训练种子已由用户取消，本阶段不含C3BF、动态障碍、其他新增导航算法或实飞。

## 1. 来源、范围与版本

官方MAVRL源码固定为`813b8875ba00c838e08286a3f8518c6167546f74`，AvoidBench固定为`b9afb971ea85a98ee98125764e93513c9cf64457`，未经修改的克隆保存在`upstream/`，交付时再次核对HEAD和工作树。已阅读[2024年arXiv v1预印本](https://arxiv.org/html/2402.08381v1)；2025年RA-L出版信息已核对，但最终发表版全文未取得，不能声称完成两个版本的全文差异核验。实现参数以固定官方源码为准，逐项依据见[SOURCE_AUDIT.md](SOURCE_AUDIT.md)。

本项目结果属于**MAVRL在Isaac Sim圆柱环境下的算法复现**，不用于声称重现原AvoidBench的实验数值。正式场景采用Poisson分布、三档密度和混合圆柱半径；uniform/clustered也已实现并做几何可行性检查，但没有完成这些分布上的策略泛化评估。

## 2. 原版与迁移版对照

| 内容 | 官方实现 | 本项目及其影响 |
|---|---|---|
| VAE | 256×256单通道，6层卷积，潜变量64，MSE＋KL | 直接加载未经修改的官方VAE代码，保持结构、损失和图像归一化 |
| LSTM | encoder均值64→单层256，FC256→3×64，共享独立decoder | 主配置重建过去10帧和当前帧，冻结encoder；10Hz下历史间隔1秒 |
| PPO actor/critic | recurrent特征256＋状态7；actor MLP256/256、critic512/512 | 保留网络、Gaussian均值tanh及执行裁剪；缓存冻结表征，只更新策略/价值头 |
| Critic重载行为 | 初始共享LSTM；源码重载默认建立独立critic LSTM | 按实际源码路径保留；离线重建只训练actor LSTM，critic LSTM不参与重建 |
| 状态 | 源码顺序与论文公式排列不同 | 保留源码顺序：log(1+dxy)、水平速度模、目标方位、速度方向、dz、vz、yaw |
| 动作 | 三维机体系加速度＋yaw rate | 保留±4/±4/±1 m/s²、±0.6 rad/s，10Hz执行；未加安全过滤器 |
| 运动学 | 0.1秒简化积分、加速度决定倾角 | 世界RFU、机体系FLU；p更新含0.5a·dt²，v+=a·dt；yaw更新不额外旋转存储速度，遵循源码语义 |
| 深度 | 双目SGM、256×256、70°、12m截断 | RTX轴向理想深度，同尺寸/FOV/安装偏移与8位量化；未复制SGM噪声和全部外参渲染细节 |
| 障碍物 | 森林、树木、灌木等 | 高8m静态圆柱覆盖允许飞行高度；半径0.5–1.8m及25%的1.8–3m大圆柱；三档间距7/5/3.5m |
| 起终点与可行性 | 随机任务与地图 | 保留源码三类任务方向，增加端点净空及网格连通性检查；未人为清空起终点直线路径 |
| 碰撞与TRAV | 点云查询及射线步进 | 圆柱膨胀后的线段相交、解析射线近似TRAV，属于几何适配 |
| 奖励与终止 | 分阶段奖励，终止奖励覆盖当步奖励 | 主模型保持源码系数及未wrap的角度误差；优先级越界→超时→碰撞→到达 |
| 初始策略 | 论文定义为不考虑障碍；公开入口为稀疏地图 | 本项目采用空障碍基础导航，明确记录与源码入口的场景差异 |
| 数据组织 | 采集深度序列、冻结encoder训练LSTM | 按真实episode截断，最多500帧，按场景拆分训练/验证；不沿用旧随机LSTM隐状态作为序列起点 |
| 运行层 | Flightgym/AvoidBench及旧Gym/SB3接口 | 独立PyTorch移植与Isaac适配，未升级共享依赖，未套用OmniDrones动力学 |

主模型initial六项奖励系数为`[-.001,-.001,-.002,-.003,-.0005,-.003]`，final为`[0,-.05,0,-.0015,-.0001,-.0015]`，速度项仅在水平速度>3m/s时激活。越界/超时/碰撞分别为−2/−5/−2，到达20/TRAV；xyz分别误差<0.4m判定到达，t>100s判定超时。计算细节及源码位置见源码审计。

## 3. 四阶段训练与实际预算

1. **初始PPO**：固定随机VAE/LSTM，训练512000步；独立50个无障碍任务到达50/50。该基础策略随后共享复用，并非各分支另训的独立种子。
2. **数据与VAE**：采集65536帧、378条连续序列，312个训练场景和66个验证场景互不重叠。VAE第242轮早停，最佳总验证loss对应epoch192；验证灰度MAE由训练前86.274降至最佳checkpoint对应2.442（0–255灰度），支持该数据分布上的重建学习。
3. **LSTM**：冻结encoder，past+current和current-only分别完成2000轮。主配置末轮验证past MSE=0.0022982、current MSE=0.0010184（0–1归一化深度）；导航使用验证最优checkpoint。current-only仍有LSTM，只取消过去帧监督。
4. **最终PPO**：三组分别冻结表征、重新初始化PPO头，均训练8000000步；baseline/fixed共享同一个past+current表征，current-only使用其单独训练的LSTM。

| 分支 | PPO步数 | PPO训练耗时 | 累计samples/s |
|---|---:|---:|---:|
| baseline | 8000000 | 6小时6分43秒 | 363.6 |
| current_only | 8000000 | 6小时6分19秒 | 364.0 |
| fixed | 8000000 | 6小时10分32秒 | 359.8 |

正式PPO为64环境、每环境1000步、minibatch4000、10 epochs，每轮64000条样本、160次梯度更新，共125轮。lr=1e-4按8m步线性衰减，gamma=.99、GAE lambda=.95、clip=.2、vf=.2、entropy=0、max_grad_norm=.5、Adam eps=1e-5。1.2m课程阈值在rollout边界检查，实际于1.216m切换。LSTM状态跨rollout保留，在episode及课程reset时清零。

以上耗时不含后续评估。current-only全流程于11月6日02:04完成，fixed随即自动启动；fixed与两组配对汇总于08:29全部完成。[原始训练曲线](../artifacts/delivery_20261106/ppo_training.png)不做平滑，1.216m附近下降来自场景/奖励切换；训练episode到达率不能代替独立评估。

## 5. 记忆与速度：结果支持什么

### 5.1 过去帧重建的训练消融

baseline对current-only的到达率分别为100/98/89%与100/99/89%。密集100任务中，两者共同成功83个、baseline单独成功6个、current-only单独成功6个、共同失败5个；中等场景单独成功为1对2。

**本轮未观察到过去帧重建提高到达率。**baseline在三个密度的平均速度略高，但只有一个训练种子，不能据此宣布普遍更优或复现论文全部记忆消融结论。current-only保留历史隐状态，不能称为完全无记忆网络。配置及共享数据/预算一致性检查见[重建目标配对报告](../artifacts/capture_recovery_20261105/memory_comparison/RESULTS.md)。

本项目遵循官方代码的10帧历史间隔，对应预印本表I的It＋It−10；预印本中最优的It＋It−20及其他未来重建组合未在本轮全部复测。

### 5.2 推理时清空记忆的诊断

| 模型 | 稀疏：正常→清零 | 中等：正常→清零 | 密集：正常→清零 |
|---|---:|---:|---:|
| baseline | 100% → 95% | 98% → 73% | 89% → 32% |
| current_only | 100% → 100% | 99% → 98% | 89% → 82% |
| fixed | 100% → 90% | 98% → 73% | 81% → 20% |

这些结果支持主模型策略依赖历史隐状态。清零会改变策略输入分布，其性能下降不能代替5.1中的重新训练消融，也不能单独证明过去帧监督优于仅当前帧监督。

### 5.3 自适应速度与目标速度奖励

baseline的平均速度由稀疏2.232降至密集1.908m/s。fixed采用训练前声明的`−0.05*abs(v_horizontal−2.0)`，只替换final阶段速度项，保留相同表征、其他奖励、动作、动力学和8m预算；目标2.0m/s及系数是本项目选择，不冒称官方公开的精确参数，详见[参数声明](FIXED_SPEED_ABLATION_PLAN.md)。该奖励不强制每步恒速。

密集场景baseline到达89%，fixed为81%；配对任务中共同成功77个，baseline单独成功12个，fixed单独成功4个，共同失败7个。baseline在该密度的实际平均速度也略低（1.908 vs 1.950m/s）。这提供了本组变速策略更好地权衡速度与避障的有限观察，不能宣称等速度显著优越、跨种子稳定优势或重现完整Pareto曲线。[速度配对报告](../artifacts/capture_recovery_20261105/speed_comparison/RESULTS.md)。

## 6. 重复性、兼容修复与数据来源

早期正式权重的三次300任务评估有一次出现15条连续记录差异，终止结局始终相同。后续3859对同状态双帧诊断捕获1对异常，重建该场景/位姿后10帧均等于原第二帧，确认原第一帧异常。所有失败记录和旧权重仍保留。

在显式Warp同步基础上，传感器接口采用`rt_subframes=2`，保持每个动作的运动学步长0.1s。该设置通过3858对同状态检查及两个独立300任务资格评估。随后重新训练主基线，得到的53个模型张量与原同seed训练逐元素一致；新旧训练的125条非资源指标记录也一致。

**本轮三组模型各自的正常评估与独立重复评估，其episode和trajectory文件SHA均完全相同。**该证据限定于本次硬件、软件与取帧设置；渲染器内部异常触发点尚未唯一定位，不作跨设备或所有未来帧绝对确定性的承诺。双子帧没有追溯应用到历史数据：共享数据、VAE和LSTM仍保留原单子帧来源，三组最终PPO采用同一双子帧设置。

兼容性修复还包括原Gym/SB3运行接口适配、episode观测与隐藏状态reset同步、源码重载critic语义、续训配置继承，以及100%到达率Wilson区间浮点舍入造成的绘图错误。绘图修复只钳制约1e-16的舍入误差，不改变原始评估指标。详情见[SOURCE_AUDIT.md](SOURCE_AUDIT.md)、[CAPTURE_SYNC.md](../audit/CAPTURE_SYNC.md)及Git历史。
